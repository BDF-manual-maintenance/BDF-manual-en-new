**错误原因**

这个错误是由于 `markupsafe` 库版本不兼容导致的。在 Sphinx 3.x 中，`jinja2` 库依赖于 `markupsafe` 库，而 `markupsafe` 库在版本 2.0.0 中移除了 `soft_unicode` 函数。因此，当 Sphinx 尝试导入 `soft_unicode` 时，会抛出 `ImportError`。

**修复方法**

1. **升级 `markupsafe` 库**：你可以尝试升级 `markupsafe` 库到版本 2.0.0 或更高。可以使用 pip 命令进行升级：
```bash
pip install --upgrade markupsafe
```
2. **降级 `jinja2` 库**：如果升级 `markupsafe` 库不起作用，你可以尝试降级 `jinja2` 库到版本 2.x。可以使用 pip 命令进行降级：
```bash
pip install jinja2==2.11.3
```
3. **更新 Sphinx 配置**：如果以上方法都不起作用，你可以尝试更新 Sphinx 配置文件 `conf.py` 中的 `extensions` 列表，确保不包含任何依赖于 `soft_unicode` 的扩展。

**需要检查的文件和配置**

1. `conf.py` 文件：检查 `extensions` 列表是否包含任何依赖于 `soft_unicode` 的扩展。
2. `requirements.txt` 文件（如果存在）：检查 `markupsafe` 库版本是否是兼容的。
3. Sphinx 版本：检查 Sphinx 版本是否是最新的。

**预防措施**

1. **保持库版本更新**：定期更新依赖库以确保兼容性。
2. **监控错误日志**：定期检查错误日志以快速发现和解决问题。
3. **测试文档编译**：在提交代码之前测试文档编译，以确保没有错误。
